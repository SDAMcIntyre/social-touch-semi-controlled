# Investigation Plan — Myelinated Mechanoreceptors on Hairy Skin

Systematic literature search for non-CT mechanoreceptor studies on hairy
skin, following the same approach as the CT-focused hairy skin investigation
(2026-06-08).

---

## Objective

Fill the gap identified in `analysis-hairy-skin-literature.md`: the
catalogued literature is heavily CT-biased. Vallbo et al. 1995 is currently
the only primary RF data source for myelinated types on the forearm. This
investigation searches for additional primary data and relevant reviews on
SA-I, SA-II, HFA, field units, and Pacinian afferents in hairy skin.

---

## Step 1 — Baseline (existing coverage)

Read and cross-reference:
- `classification-receptive-field.md`
- `classification-receptive-field-extended.md`
- `SUMMARY.md` (detailed summaries of core papers)

Already catalogued non-CT hairy skin papers:
- Vallbo et al. 1995 — 5 myelinated types, forearm (primary data)
- Edin & Abbs 1991 — SA-I, SA-II, FA-I, FA-II, dorsal hand (primary data)
- Edin 1992 — SA-I, SA-II strain sensitivity, dorsal hand (primary data)
- Nagi et al. 2019 — A-HTMRs on forearm (primary data)
- Macefield 2005 — all classes review
- Corniani & Saal 2020 — whole-body density estimates

## Step 3 — For each paper found

Record:
- Full citation (authors, year, title, journal, DOI)
- Species and body site
- Afferent types studied
- Key RF findings (size, shape, subfield count, density)
- Method (microneurography, histology, psychophysics, computational)
- Whether it reports **new RF data** or only references existing values
- Whether it is already in the classification files

---

## Step 4 — Synthesis

Write an analysis file (`analysis-hairy-skin-myelinated-literature.md`) with:
1. **Coverage update** — new papers found, classified by afferent type
2. **Quantitative benchmarks** — consolidated RF size/density table for
   myelinated types on hairy skin, extending the CT-focused analysis
3. **Glabrous comparison** — side-by-side table of RF sizes on hairy vs
   glabrous skin per afferent type
4. **Literature gaps** — what remains uncharacterised
5. **Citation hierarchy** — tiered relevance to the naturalistic RF article
6. **Updates to classification files** — list of entries to add to
   `classification-receptive-field-extended.md`

Either:
- (a) Additional primary data papers exist and fill out the myelinated

- (b) The literature is genuinely as thin as it appears — document this as
